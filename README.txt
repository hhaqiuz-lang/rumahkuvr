RUN LOCALLY
1. Put index.html, style.css, and script.js in the same folder.
2. Create an images folder and add your screenshots using the filenames above.
3. Double-click index.html to open it directly in a browser.

Recommended local development option:
- Open the folder in VS Code.
- Install the Live Server extension if desired.
- Right-click index.html > Open with Live Server.

HOST ON GITHUB PAGES
1. Create a new GitHub repository, for example: rumahkuvr-portfolio.
2. Upload index.html, style.css, script.js, and the images folder to the repository root.
3. Open the repository on GitHub.
4. Go to Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and / (root) folder.
7. Save the settings.
8. GitHub will provide the published Pages URL after deployment.

CONTENT TO REPLACE BEFORE FINAL PRESENTATION
- images/hero.jpg: real main gameplay/project screenshot.
- All gameplay gallery image files.
- Gameplay video placeholder in index.html.
- Team names, roles, responsibilities, and profile images.
- Contact/demo links.
- Optional Windows build area when a real downloadable build is available.

IMPORTANT
The contact form is frontend-only. It does not send messages until you connect it to a real backend or a form service.
